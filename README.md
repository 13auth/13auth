## hey, i'm Batuhan 👋

<img align="right" width="440" src="https://github.com/13auth/spatial-canvas/raw/main/assets/demo.gif" alt="Spatial Canvas" />

solo developer from Türkiye. i build software from scratch — the stuff most
people grab a library or a SaaS for, i'd rather build myself and actually
understand how it works, down to the metal.

best proof i've got: **[Spatial Canvas](https://github.com/13auth/spatial-canvas)**
— a window manager i wrote from the ground up in **C++ and Direct3D 11**. your
live Windows windows on an infinite, zoomable canvas: zoom in and you drop into
the *real* app — no screenshots, no fake input. one of the very few live-window
zoomable desktops out there, on any OS.

the rest of the time i'm shipping Windows, iOS and web apps, automating whatever
is wasting my time, and using whatever language the problem actually needs.

no company, no roadmap, no team. just me, picking problems that look too hard and
not stopping until they work. `13auth` is the name i put on it.

everything public is in the repos below 👇
